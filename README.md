# Wood Carving Decor homepage concept

WordPress / Divi / WooCommerce target. See `wordpress/README.md` for the installable shortcode plugin and Code Module alternative. `index.html` is the standalone design preview. `dist/` contains only the preview and optimized assets.

Local preview: `python3 -m http.server 5173 --bind 127.0.0.1` then open http://localhost:5173/.

Rebuild the preview and WordPress package after editing source files using `python3 package.py`. Original Dropbox files remain unchanged. This phase contains no commerce backend and has not been deployed.

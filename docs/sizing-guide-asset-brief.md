# Sizing guide — proposed asset brief (pending user choices)

User confirmed: Corbels and Capitals first, shown in room-context scenes. Convert the former collection introduction (“Know what you’re looking at”) and place it immediately below the plan. A clearly labeled interactive SVG room placeholder is now implemented.

Recommended initial set: one representative design from each included product type, photographed/rendered in each actual offered size. Four types with three sizes each means twelve individual front-view assets, provided those size counts are confirmed. The guide should say that it compares representative designs, not every SKU.

- Use the same front-facing angle, lighting, finish and background treatment for every size of a given design.
- Prefer tightly bounded transparent PNGs, at least 1200px on the longest edge, with the full carving visible. Keep shadows separate or consistent.
- Supply a table mapping each image to product name/SKU, exact width, height and depth, units, and size/variant identifier. Do not assume every type has exactly three sizes.
- Record the visible object bounds if canvas padding varies. The interactive layout should calculate displayed sizes from confirmed dimensions; independently fitting every image into an equal box would erase the comparison.
- A shared baseline and a dimension ruler make side-by-side comparison clear. Corbels/capitals also benefit from a side profile showing projection, which can follow as a second view.
- Group by product type using manual tabs; show the three sizes together for that type. On phones use a compact comparison canvas or manually swipeable row with controls.
- Until dimensions are supplied, any mock comparison must be labeled “Illustrative proportions — dimensions pending” and must not imply real sizes or availability.

For the first set, supply one corbel design and one capital design in their confirmed sizes: six room-context assets if each actually has three sizes. Keep the room, camera, lens, crop, perspective, lighting, and all reference objects fixed between sizes. Only the actual product size should change. Supply the product-only files too if available, plus exact dimensions. Context conveys perceived scale; dimensions remain necessary for fit. Current Small/Medium/Large labels and scale factors are illustrative and must be replaced by actual variants.
